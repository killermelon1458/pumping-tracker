# Pumping 1.4.10 Beta

Offline-first pumping and milk-inventory tracking for Android **8.0/API 26+**. Version code **17**; production ID **dev.killermelon1458.pumping**. Targets API 36; compiles against API 37.

## Changes since 1.4.8-beta

- **Customize each editor:** Quick Log/Edit Pump, New Bag and Use Milk have independent saved section order and optional visibility. Drag handles, accessible Up/Down, Reset, Done and Cancel are supported. Required fields stay visible; recorded information and unsaved drafts are preserved when sections are hidden.
- **Compact organization:** Time picker and Edit Layout remain small text buttons at the scrollable bottom. Layout controls use one row with the drag handle on the right. Save/Cancel stay fixed at the top.
- **Choose your time picker:** one global Clock face (default) or Scroll wheels preference. Date and time remain independent; Done applies once and Cancel preserves the draft, with 12/24-hour support. The existing wheel implementation is retained.
- **Stash editing parity:** New Bag and Use Milk share the modern timestamp controls and semantic discard checks. Untouched/reverted forms close cleanly; incomplete drafts remain protected.
- **Cleaner history:** unspecified breastfeeding context no longer adds a label to history tiles. Yes/No and independent baby/power/stash indicators retain their meaning. Stored Unknown values and statistics filters are unchanged.

Existing Quick Log timing, pump profiles, power-pump intervals, statistics, reminders and inventory behavior are retained.

## Upgrade and backup compatibility

Export a private native JSON safety backup, then install **Pumping-1.4.10-beta.apk** over the production installation **without uninstalling or clearing storage**. Public updates use the permanent production identity/certificate; Pumping Dev remains a separate app. Room stays **schema 6** and native JSON stays **v4**; older native imports and original iOS `.pumping` imports remain supported.

Layouts and time-picker style are **device-local UI preferences**, excluded from native/iOS backups. Existing installations without a picker preference default to Clock face and default editor layouts; saved record values are preserved.

Native JSON v4 is the complete-fidelity saved-record backup option. Legacy `.pumping` export still refuses records it cannot safely represent, including newer Android metadata and unsupported timing/inventory operations. **Stage 4B's lossy-export workflow is deferred.** Original iOS acceptance of exported files remains unverified. Export files are not encrypted; retain them privately.

## Verification and beta limitations

The owner physically accepted 1.4.10-dev. Its recorded verification is reused: **337 debug + 337 release unit tests**, **122 distinct emulator/Compose cases** (full sweep plus a corrected test-helper rerun), **13 tooling tests**; debug/release lint each **0 errors / 20 existing warnings**. The actual debug 1.4.9→1.4.10 update preserved synthetic records, links, balances, deletion markers, layouts, picker/reminder preferences, backups and restart persistence.

Production signature verification, a signed in-place 1.4.8-beta upgrade and focused fresh-install smoke testing are mandatory publication gates; their actual results and the APK checksum belong in the release asset verification report. Development testing does not establish a production-phone upgrade. Extended Samsung sound/vibration/heads-up, OEM battery restrictions, additional Android-version smoke tests and broader accessibility testing remain post-release/device-specific checks. No new full development campaign is implied by this promotion.
