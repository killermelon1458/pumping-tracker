# Pumping 1.4.8 Beta

An offline-first Android pumping and milk inventory tracker. This beta collects the accepted development improvements since **1.4.0-beta.1**. Android **8.0/API 26 or newer**; targets API 36 and compiles against API 37. Version code **15**, production app ID **dev.killermelon1458.pumping**.

## What's changed since 1.4.0-beta.1

- **Breastfeeding context:** one-tap Yes / No / Not specified before pumping. Historical and imported entries remain truthfully Not specified until explicitly changed.
- **My Pumps:** stationary, wearable, manual and custom profiles with optional details, generated/editable nicknames, quick selection and archiving. Stable IDs preserve historical attribution after renaming or archiving.
- **Power Pump:** a fast classification toggle plus optional, editable pumping/rest intervals. The optional 20/10/10/10/10 preset records 40 active and 60 elapsed minutes as one session. Basic entries do not invent unrecorded rests.
- **Quick Log timing:** the last two distinct edited fields determine Start/End/Duration. Valid Duration edits synchronize immediately without keyboard Done. Future End times require confirmation. Timer pauses and recorded active time remain separate.
- **Independent date/time controls:** date-only calendar and time-only scroll wheels, 12/24-hour preference, AM/PM boundary handling, explicit Done/Cancel and a compact accessibility/landscape fallback.
- **Discard confirmation:** opening an editor or dismissing a picker no longer produces a false warning. Reverting all values clears the warning; incomplete drafts are protected.
- **History indicators:** breastfeeding and power-pump outline icons alongside the existing blue stash snowflake, with accessible descriptions.
- **Filterable statistics:** combine date range, multiple pumps, breastfeeding context and pumping mode. Compare pumps or breastfeeding groups under identical filters. Includes count, total, mean/median, left/right totals and aggregate milk per active minute. Known elapsed-time statistics display eligible sample sizes and exclude nominal basic power spans. Existing charts, goals, streaks and independent Stash analytics remain.

Sessions, timers, stash bags/transactions, linked deletion, units and existing reminder Snooze/Dismiss behavior are retained.

## Upgrade and backups

Install **Pumping-1.4.8-beta.apk** over the production app; do not uninstall it or clear storage. It uses the same permanent production certificate as 1.4.0-beta.1 and a higher version code. Export a private safety backup first. Pumping Dev is a separate installation and is not the production update.

Room upgrades **3→4→5→6** preserve existing records. Historical breastfeeding/power classifications remain Unknown internally, displayed as Not specified; old sessions are not assigned a pump automatically.

**Native JSON v4 is the complete-fidelity saved-record backup option**, including profiles, archived associations, phases, context, notes, inventory and deletion markers. Older native v1/v2/v3 backups and original iOS `.pumping` imports remain supported. Imports preview changes and merge by stable IDs; deleted records stay deleted during repeated merges. Backup preference restoration covers the supported snapshot; it does not activate live reminder schedules.

Some Android records cannot currently be exported to the original `.pumping` format, including newer context/profile/power metadata and unsupported timing or inventory operations. Export refuses unsafe or silently lossy conversion. **Stage 4B's optional lossy-export workflow is deferred.** Original iPhone acceptance of exported legacy files remains unverified. `.pumping` obfuscation and native JSON are not encryption; keep exports private.

## Verification and limitations

Verification completed so far: **310 debug + 310 release unit tests**, **78 Compose/emulator workflows**, **13 tooling tests**; debug/release lint each **0 errors / 20 existing warnings**. Migration tests include API 26/35 Robolectric coverage. The exact signed APK passed an in-place update from the production APK downloaded from the original GitHub release, using synthetic records on a disposable API 36.1 emulator. Historical fields, relationships, balances, deletion suppression, supported settings, repeat native/iOS imports and restart were preserved. A separate empty signed installation restored and re-exported v4 profiles, archived associations, phases and prior data; the internal settings acknowledgement token refreshes by design while record identities and preference values remain unchanged.

The production reminder also delivered while the app was backgrounded/killed and the display locked. Snooze dismissed it without opening the app and actually redelivered after five minutes; Dismiss cleared it while retaining a future alarm. No duplicate notification or record mutation occurred. Notification permission and precise-alarm access were granted on the disposable test emulator. No production-phone upgrade testing is claimed. Owner acceptance covers the 1.4.8 development UX; Samsung One UI battery management, exact-alarm access, notification sound/vibration/heads-up and device-specific accessibility remain physical-device checks. Reminders respect notification permission, channel settings and Do Not Disturb; unavailable exact scheduling uses an inexact fallback.

Statistics describe expressed milk, not infant intake or inherent pump effectiveness. Small samples and feeding/time-of-day differences require care.
